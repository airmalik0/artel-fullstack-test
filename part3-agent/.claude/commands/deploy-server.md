description: Развернуть выходной VPN-узел (Xray Reality и Hysteria2) на сервере
argument-hint: <host>
---

Разверни VPN-узел на сервере `$ARGUMENTS`. Подзадачи отдавай подагентам, они вернут тебе JSON
шагов. Сам команды шагов не повторяй, если подагент уже прогнал их.

1. Подагент `recon`: шаг `recon`. Если `ok: false`, переходи к пункту 5.
2. Подагент `deployer`: шаги `harden`, `xray`, `hysteria`, `clientcfg` по порядку.
3. Если шаг упал, подагент `troubleshooter` разбирает причину и чинит. Потом снова `deployer` с
   упавшего шага. Не больше двух попыток на один сбой.
4. Подагент `verifier`: итоговая проверка. Если `ok: false`, `troubleshooter` и повторная проверка,
   тоже не больше двух раз.
5. Закрой работу: последний вызов `./scripts/verdict.sh $ARGUMENTS` делает `verifier`, ты читаешь его вывод.

Итог напиши коротко, только из `verdict.json`: `ok`, проверки транспортов, сколько изменений
сделал этот прогон (`changed_this_run`), что снимал с портов и что осталось нерешённым.
